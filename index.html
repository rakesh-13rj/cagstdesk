Start here

1. Enter business GSTIN and return period in your working file. 2. Import a CSV sales report or enter an offline sales invoice. 3. Review every row and tax treatment. 4. Export the working register and summary for review.

Supported generic CSV column names include: invoice_no, invoice_date, customer_name, customer_gstin, place_of_supply, taxable_value, gst_rate, cgst, sgst, igst, invoice_total, platform, supply_type. Column mapping is basic in this starter; check the preview before relying on imported values.

This starter reads CSV files. Excel (.xlsx) support, platform-specific mapping, return/refund netting and full validation are next-stage features. Do not upload passwords, bank credentials or other unnecessary sensitive data.

Before production / GST Portal upload

  • Download the latest official GST Returns Offline Tool and its current templates.
  • Map each platform report’s fields to the applicable GSTR-1 tables, including B2B, B2C, credit/debit notes, exports, HSN and e-commerce operator sections where relevant.
  • Validate invoice counts and taxable/tax totals; check duplicates, cancellations, returns and credit notes.
  • Generate portal-compatible JSON only after implementing and testing the current official schema.

Official GST Portal guide: https://tutorial.gst.gov.in/userguide/returns/GSTR_1.htm
